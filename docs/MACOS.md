# iCloud Photo Downloader для macOS

Нативный интерфейс SwiftUI для Apple Silicon, целевая версия — macOS 13 и новее. Английский и русский языки переключаются в окне приложения без перезапуска. Вся работа с iCloud и файлами выполняется тем же Python-движком, что и в Windows. Дополнительные ограничения iCloud перечислены в основном README. Проект не связан с Apple.

## Сборка

Нужны Apple Silicon, Command Line Tools или Xcode, `uv` и интернет для установки зависимостей. Используйте Python 3.12, собранный для macOS 13 или более ранней версии. Например:

```sh
uv python install 3.12
IPD_PYTHON="$(uv python find 3.12 --managed-python)" ./build-macos.sh
```

Скрипт создаёт собственное окружение `.venv-macos`, устанавливает зависимости, запускает тесты, собирает Python-процесс и SwiftUI-приложение с иконкой из общей графики проекта, проверяет минимальную версию всех встроенных Mach-O и подписывает результат локальной ad-hoc подписью. Результат: `dist/iCloud Photo Downloader.app`. Перед повторной сборкой закройте приложение.

Сборка с другим Python возможна через `IPD_PYTHON=/путь/к/python3.12`; если какая-либо бинарная зависимость требует macOS новее 13, проверка завершит сборку с ошибкой. Проверка заголовков не заменяет запуск на macOS 13.

Чтобы собрать вторую копию, не заменяя уже запущенное приложение, задайте путь в `IPD_MACOS_APP`. Например, `IPD_MACOS_APP='dist/iCloud Photo Downloader — исправлено.app'`.

В этой версии нет сертификата Developer ID и нотариального заверения Apple. На другом Mac Gatekeeper может блокировать приложение; для распространяемого релиза владельцу проекта потребуется подписать и нотариально заверить пакет. App Store не используется. Для распространения также проверьте применимые лицензии: в приложении находятся лицензия проекта и уведомления, поставляемые установленными пакетами; зависимости и их лицензии перечислены в основном README. Qt и libheif включаются как отдельные динамические библиотеки.

Язык самого приложения переключается сразу. Стандартные меню и элементы системного окна выбора папки показывает macOS в соответствии с системным языком; заголовок окна, его описание и кнопка выбора используют язык приложения.

Предварительный подсчёт проверяет медиатеку и показывает число просмотренных объектов, но не скачивает их. Если начать загрузку в течение пяти минут после подсчёта, не меняя аккаунт, период и настройки, приложение использует его результат повторно. Свободное место и состояние файлов проверяются при загрузке. После перезапуска приложения или изменения настроек нужен новый подсчёт.

## Проверка без настоящего iCloud

```sh
IPD_FAKE=40 "dist/iCloud Photo Downloader.app/Contents/MacOS/iCloudPhotoDownloader"
```

Введите любой тестовый Apple ID и пароль `secret`, выберите отдельную временную папку и запустите предварительный подсчёт или загрузку. Данные демонстрации сохраняются отдельно от настоящих в системной временной папке. Для полной изоляции можно задать путь к пустой папке в `IPD_DEMO_APPDATA`. Демо не обращается к настоящему iCloud.

## Данные и конфиденциальность

- Настройки, сессии и состояние заданий: `~/Library/Application Support/iCloudPhotoDownloader/`.
- Журналы: `~/Library/Logs/iCloudPhotoDownloader/`.
- Пароли: системная Связка ключей macOS. Пароли и коды подтверждения передаются фоновому процессу только по локальному каналу, а не в аргументах командной строки.
- Выбранная папка с фотографиями не находится внутри приложения. Удаление аккаунта из приложения не удаляет фотографии или базу состояния.

Перед передачей сборки проверьте, что она не содержит ваши настройки, токены, журналы или фотографии; не передавайте свою рабочую папку проекта и пользовательскую папку приложения.

## Ручная проверка перед релизом

1. Проверить установку и запуск на чистом Apple Silicon Mac с macOS 13 и на актуальной версии macOS.
2. Проверить русский и английский язык, смену языка во время работы и сохранение выбора после перезапуска.
3. На тестовой медиатеке проверить выбор папки, альбомы, подсчёт, загрузку, паузу, остановку, возобновление и повторный запуск без дублей. Проверить поведение с отключённым диском и заполненным диском.
4. С владельцем аккаунта проверить реальный вход, повторный вход из Keychain, код 2FA, SMS, Live Photo, HEIC/Compact, выбранные альбомы и сообщение об истечении сессии. Вход и загрузка реального аккаунта в рамках автоматических тестов не выполняются.
5. Проверить меню строки состояния, уведомления, работу после закрытия окна и завершение активной загрузки при выходе.
6. Проверить состав `.app`, лицензии и отсутствие личных данных; после Developer ID и нотариального заверения проверить Gatekeeper на чистой машине.
