# Ручная проверка на реальном аккаунте

Разделы 1–5 проходятся через командную строку, раздел 6 — в окне. В командах `ACC` — ваш Apple ID, `ROOT` — пустая папка для проверки.

## 1. Вход

- [ ] `python -m ipd_app login --account ACC` спрашивает пароль (видны звёздочки), затем код 2FA и пишет «Вход выполнен».
- [ ] Повторный запуск той же команды ничего не спрашивает.
- [ ] `python -m ipd_app albums --account ACC` печатает ваши альбомы; «Скрытые» и «Недавно удалённые» в списке нет.

## 2. Небольшой период

Выберите месяц, где 20–50 снимков.

- [ ] `python -m ipd_app sync --account ACC --root ROOT --from 2024-05-01 --to 2024-05-31 --dry-run` показывает правдоподобное число файлов и объём, в папке пусто.
- [ ] Та же команда без `--dry-run` скачивает файлы в `ROOT\2024\05 May\Full size` и создаёт JPG в `Compact`.
- [ ] Число файлов совпадает с тем, что показывает «Фото» за этот месяц (с поправкой на видеочасти Live Photos).
- [ ] 2–3 снимка, сделанных в другом часовом поясе или около полуночи, лежат в правильном месяце.
- [ ] JPG из `Compact` открываются стандартным просмотрщиком, не лежат боком, в свойствах стоит дата съёмки.
- [ ] Повторный запуск: «Скачано: 0», занимает секунды.

## 3. Сбои

- [ ] Выдернуть сеть посреди загрузки: задание либо дожидается сети и продолжает, либо завершается с ошибками по отдельным файлам. В папках нет файлов нулевого или неполного размера, после повторного запуска всё докачано.
- [ ] Нажать Ctrl+C посреди загрузки, запустить снова: программа предлагает продолжить, дублей нет, файлов `.part` не остаётся.
- [ ] Удалить один скачанный файл вручную и запустить снова: файл скачивается заново.
- [ ] Заменить один скачанный файл файлом другого размера: он не тронут, в отчёте конфликт.

## 4. Второй аккаунт

- [ ] `login` и `set-root` для второго Apple ID с другой папкой, `sync` кладёт файлы в неё.
- [ ] `set-root` второго аккаунта на папку первого выдаёт предупреждение.

## 5. Что записать по итогам

- Заполнен ли часовой пояс съёмки: остаётся ли папка `_incoming` пустой для большинства снимков.
- Были ли ошибки «размер скачанного файла не совпал» и для каких типов файлов.
- Сообщение при выключенном «Доступе к данным iCloud через веб», если есть возможность проверить.
- В `%LOCALAPPDATA%\iCloudPhotoDownloader\logs\app.log` нет пароля, кода 2FA и полного Apple ID.

## 6. Окно и трей

Запуск: `python -m ipd_app`. Для репетиции без iCloud: `python -m ipd_app gui --fake 40`, пароль `secret`.

- [ ] Первый запуск без аккаунтов открывает диалог входа. После пароля появляется страница кода; неверный код даёт сообщение, а не закрытие окна.
- [ ] Кнопка «Прислать SMS» отправляет код на телефон, и он принимается.
- [ ] Сразу после входа программа просит выбрать папку. Пока папка не выбрана, «Запустить задание» неактивна и рядом написано почему.
- [ ] Начало периода позже конца: кнопка неактивна, рядом подсказка.
- [ ] После запуска появляется сводка (сколько в периоде, сколько уже есть, сколько качать), затем идут файлы, объём, скорость и оставшееся время. Окно при этом двигается и отвечает на нажатия.
- [ ] «Пауза» останавливает рост объёма, «Продолжить» возобновляет. «Остановить» завершает задание, в блоке «Последний запуск» видна причина.
- [ ] Крестик прячет окно, значок остаётся в трее, появляется уведомление. Загрузка продолжается (подсказка значка показывает счётчик).
- [ ] Значок меняет цвет: синий в ожидании, зелёный при загрузке, красный после ошибки.
- [ ] По окончании задания приходит уведомление Windows с итогом.
- [ ] Меню трея: «Открыть», «Пауза», «Остановить», «Выход» работают. «Выход» при идущем задании спрашивает подтверждение.
- [ ] Повторный запуск программы при уже работающей не открывает вторую копию, а показывает окно первой.
- [ ] Закрыть программу посреди задания и открыть снова: предлагает продолжить задание с теми же датами.
- [ ] Во время задания список аккаунтов заблокирован, «Сохранить» в настройках неактивна.
- [ ] «Аккаунты» → «Удалить»: аккаунт исчезает из списка, файлы в папке остаются.
- [ ] «Журнал» показывает записи, фильтр по уровню работает, «Открыть папку с логами» открывает Проводник.
- [ ] Окна читаемы при масштабе экрана 125 % и 150 % и в тёмной теме Windows.

## 7. Установщик

- [ ] `.\build.ps1` доходит до конца и печатает путь к `dist\iCloudPhotoDownloader-Setup-<версия>.exe`.
- [ ] Установка проходит без запроса прав администратора. SmartScreen показывает предупреждение, «Подробнее» → «Выполнить в любом случае» работает.
- [ ] В меню «Пуск» появился ярлык, программа запускается, значок правильный.
- [ ] На компьютере без Python (в идеале чистая Windows 11) программа запускается, вход и небольшое задание работают, HEIC превращается в JPG.
- [ ] Установка той же или новой версии поверх: аккаунты, папка и настройки на месте, вход не требуется.
- [ ] Удаление с ответом «Нет» на вопрос о настройках: программа удалена, папка `%APPDATA%\iCloudPhotoDownloader` осталась, фото на месте.
- [ ] Удаление с ответом «Да»: папки в `%APPDATA%` и `%LOCALAPPDATA%` удалены, в «Диспетчере учётных данных» нет записи `iCloudPhotoDownloader`, фото на месте.
